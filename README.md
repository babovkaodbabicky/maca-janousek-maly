# Git Projekt

## Popis projektu

Jednoduchý projekt vytvořený pro procvičení základních funkcí systému Git a platformy GitHub.

Projekt obsahuje několik textových souborů s poznámkami a úkoly.

## Instalace a spuštění

Projekt nevyžaduje žádnou instalaci.

Stačí stáhnout nebo naklonovat repository a otevřít textové soubory v libovolném textovém editoru.

## Autoři

- Tvoje jméno
- Jméno spolužáka

## Rozdělení práce

### Tvoje jméno

- vytvoření základní struktury projektu
- práce na souboru napad.txt
- úprava README
- vytvoření Pull Requestu

### Jméno spolužáka

- práce na souboru ukoly.txt
- práce na souboru poznamky.txt
- úprava dokumentace
- code review

## Struktura projektu

- `README.md` – dokumentace projektu
- `.gitignore` – soubory ignorované Gitem
- `docs/` – textové dokumenty
- `assets/` – obrázky
