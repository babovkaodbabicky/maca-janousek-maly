# Git Projekt

## Popis projektu

Jednoduchý projekt vytvořený pro procvičení základních funkcí systému Git a GitHubu.

## Instalace a spuštění

Projekt nevyžaduje žádnou instalaci.

Stačí naklonovat repository a otevřít textové soubory v libovolném textovém editoru.

- `README.md` – dokumentace
- `.gitignore` – ignorované soubory
- `docs/` – textové dokumenty
- `assets/` – obrázky
